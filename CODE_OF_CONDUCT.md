# Code of Conduct

Kube-Policies adopts the **CNCF Code of Conduct** as its community standard.

The full text is maintained by the Cloud Native Computing Foundation at:
<https://github.com/cncf/foundation/blob/main/code-of-conduct.md>

All participants in this project — contributors, maintainers, and anyone
interacting in project spaces (GitHub issues, pull requests, discussions, or
any other channel) — are expected to uphold that code.

## Scope

This Code of Conduct applies to all project-affiliated spaces, including:

- The GitHub repository (issues, pull requests, code review comments, discussions)
- Any project communication channels (Slack, mailing lists, community calls)
- Project events or meetups where individuals represent this project

It applies to all participants regardless of seniority, affiliation, or role.

## Enforcement

Violations are reviewed by the project maintainer(s). Depending on severity,
responses may include:

1. **Correction** — a private written warning with an explanation of the
   violation and why it was inappropriate.
2. **Warning** — a formal warning with restrictions on interaction for a
   specified period.
3. **Temporary ban** — temporary removal from project spaces.
4. **Permanent ban** — permanent removal from all project spaces for severe or
   repeated violations.

Decisions are made in good faith. Anyone who believes an enforcement decision
was incorrect may appeal by contacting the maintainer (or, once the project
grows to multiple maintainers, by contacting a maintainer who was not involved
in the original decision).
